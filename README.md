## 🚀 Projeto em destaque

### [Sistema de Monitoramento Preventivo de Validades](https://github.com/davidribeiro-cmd/google-sheets-expiration-alerts)

Sistema que avisa com antecedência quais produtos estão perto do vencimento, para que a equipe aja antes que eles virem perda. Nasceu como uma solução para o meu clube e, desenvolvido em parceria com um colega, hoje está em **mais de 45 clubes do Sam's Club**.

| 📉 Redução de perdas no piloto | 🏬 Clubes usando | 💰 Custo operacional |
|:---:|:---:|:---:|
| **23%** | **+45** | **Zero** |

- Cadastro padronizado pelo **Google Forms**
- **Google Sheets** como banco de dados, com preenchimento automático pela base de produtos
- Alertas por e-mail em 30, 7 e 3 dias e no dia do vencimento, enviados só para o responsável de cada setor
- Relatório completo do setor em **PDF** anexado a cada alerta
- Itens vencidos movidos automaticamente para um histórico

`JavaScript` `Google Apps Script` `HTML` `CSS` `Google Sheets` `Google Forms`
